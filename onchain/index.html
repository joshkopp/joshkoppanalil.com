How it stays fair, and check a roll

One seed covers the whole session. The house posts its fingerprint to devnet before your first bet, and you fix your own seed at the same moment, so every outcome in the session is already decided: roll number 1, 2, 3 and so on are fixed functions of the two seeds. That is what stops the house dropping a roll it dislikes — asking again for the same roll number returns the same number. Roll numbers run without gaps, so a missing one is visible in the reveal.

roll = HMAC-SHA256(seed, playerSeed:rollNumber), first 32 bits scaled to 0.00 to 99.99. Fingerprint is SHA-256(seed). House edge 1%.

Built for the University Blockchain Conference 2026 hackathon by Josh Koppanalil. Solana devnet only. Chips and devnet SOL have no value, and nothing here is a wager.

The house runs as a server function whose source is in the repo. Your browser never trusts it: on reveal it rechecks the seed against the fingerprint that was already on the chain, recomputes every roll, and flags any gap in the roll numbers. If the house is unreachable the game falls back to a house in your browser and says so.
